curatrix Reference
==================

This document is the reference of the XDMOD tools: the ``curatrix`` command line, its Python
API, the XDMOD Sphinx extension, the shared needs configuration and the SysML library. The
method itself is explained in the :external+xdmod-manual:doc:`XDMOD Manual <index>`; the
check catalogue, with one need per check, is in its
:external+xdmod-manual:doc:`reference/checks` page.

Most of this document is generated from the code and the configuration in xdmod, so it can't
drift from what the tools do.
